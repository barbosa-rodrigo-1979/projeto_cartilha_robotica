PARTE 1: O QUE DIABOS É A BNCC E O RCP-PR?

(E POR QUE VOCÊ DEVERIA SE IMPORTAR, OU "A BUROCRACIA QUE TE SALVA")

📚 BNCC: A Bíblia da Educação (Ou "O Livro de Regras do Jogo da Vida")

A BNCC é o documento que define o que todo estudante brasileiro tem o direito de aprender em cada etapa da Educação Básica. Ela não é uma lista de conteúdos decorados (tipo "decoreba para a prova"), mas sim um mapa das competências e habilidades que formam um cidadão preparado para o século XXI. É o que separa um mero "apertador de botões" de um criador de soluções.

Pense na BNCC como o Roteiro de um Filme de Herói. Ela não te diz exatamente como salvar o mundo, mas te dá as ferramentas e o treinamento básico para que você possa, quando chegar a hora, criar sua própria aventura épica.

Para a área de Ciências da Natureza, a BNCC organiza o aprendizado em três unidades temáticas que se repetem ao longo de todo o Ensino Fundamental, como se fossem os três atos de uma peça:

Unidade Temática O que aborda Analogia para Programadores
Matéria e Energia Propriedades dos materiais, fontes e transformações de energia. Entender de onde vem a energia para o seu código rodar e como ela se transforma em luz, som e movimento. É a física do seu programa.
Vida e Evolução Seres vivos, ecossistemas, saúde e corpo humano. Seu código precisa estar "vivo" e interagir com o ambiente. É a biologia do seu sistema, como ele reage a estímulos.
Terra e Universo Astronomia, geologia, clima e sustentabilidade. Onde seu código se encaixa no mundo? Ele pode monitorar o clima, ajudar na sustentabilidade ou até simular um sistema solar?

No Ensino Médio, a BNCC estabelece competências específicas para a área de Ciências da Natureza e suas Tecnologias, que incluem a capacidade de analisar, representar e prever fenômenos naturais e tecnológicos. É aqui que você para de ser um mero usuário e se torna um engenheiro do caos digital.

📍 RCP-PR: A Versão Paranaense (Ou "A Receita de Bolo com Ingredientes Locais")

O RCP-PR é a versão paranaense da BNCC. Ele pega a Base Nacional e adapta à realidade do estado do Paraná, acrescentando especificidades locais e contextualizando os objetivos de aprendizagem. Imagine que a BNCC é a receita de bolo base, e o RCP-PR adiciona um toque de pinhão e um pé de moleque no final.

Na prática, os códigos da BNCC (como EF07CI04) ganham um sufixo no Paraná (ex: PR.EF07CI04.s.7.27), mas o conteúdo da habilidade é o mesmo. É como um código de barras: o número é diferente, mas o produto é o mesmo.

🎯 Por que isso importa para o micro:bit? (Ou "Por que você não está só brincando de robô")

Porque programar um micro:bit não é só "brincar de robô". É uma oportunidade de desenvolver habilidades previstas na BNCC e no RCP-PR que vão te fazer um ser humano mais completo e um profissional mais desejado. Você não está só aprendendo a programar; está aprendendo a pensar, a resolver problemas e a criar o futuro.

Código BNCC/RCP O que a habilidade diz Como o micro:bit ajuda (O Mindset do Guerreiro)
EF07CI04 Avaliar o papel do equilíbrio termodinâmico para a manutenção da vida e funcionamento de máquinas. Você não está só piscando um LED; você está controlando a energia. Ao programar sensores, você entende como sistemas convertem energia, como o calor da sua mão pode ser lido pelo termômetro do micro:bit.
EF08CI03 Classificar equipamentos elétricos pela transformação de energia (térmica, luminosa, sonora, mecânica). Você está se tornando um mestre da energia. O micro:bit converte energia elétrica em luz (LEDs), em movimento (acelerômetro) e em som (alto-falante). Você decide o que fazer com ela.
EF09CI03 Identificar modelos que descrevem a estrutura da matéria. Programar é criar modelos. Seu código é um modelo do que você quer que o mundo faça. A lógica de programação modela sistemas complexos de forma simplificada.
EM13CNT101 Analisar e representar transformações e conservações em sistemas. O código não é só uma receita; é uma representação da realidade. O comportamento do seu sistema micro:bit é uma previsão do que você programou.
EM13CNT102 Construir protótipos de sistemas considerando variáveis e tecnologias digitais. Cada projeto com micro:bit é um protótipo funcional. Você não está só imaginando; você está construindo. É o sonho de todo inventor.
EM13CNT303 Interpretar textos de divulgação científica em diferentes mídias. Você vai documentar e comunicar seus projetos. Ser um cientista não é só fazer, é também mostrar e explicar o que fez.

Resumo da ópera: você não está só aprendendo a programar; está construindo habilidades que a BNCC e o RCP-PR consideram essenciais para sua formação. E de quebra, ainda vai se divertir pra caramba e ter o poder de criar coisas que vão deixar seus amigos de boca aberta.

📝 O Código Inicial: O Que Ele Faz E Como Explodi-lo

Quando você cria um projeto novo, o MakeCode já coloca um código inicial:

input.onButtonPressed(Button.A, function () {
  basic.showString("Hello!")
})

Isso é JavaScript (na verdade, TypeScript, mas ninguém liga). Ele faz o micro:bit mostrar "Hello!" quando você pressiona o botão A.

Bonito, né? Fofo, mas fraco. Você vai aprender a fazer coisa muito mais insana. Vamos transformar esse código em algo que faria o próprio micro:bit tremer de medo (se ele pudesse tremer).

Antes de sair escrevendo código como um louco, você precisa entender o básico do JavaScript no MakeCode. Não é um bicho de sete cabeças, é um bicho de dez cabeças, mas você vai domá-lo.

Os Blocos de Construção (A Sua Caixa de Ferramentas)

Comando O que faz Exemplo O que você pode fazer com isso
basic.showString("texto") Mostra um texto rolando na matriz de LEDs. basic.showString("OLÁ, MUNDO!") Criar mensagens secretas, fazer o micro:bit falar (digitalmente).
basic.showIcon(IconNames.Heart) Mostra um ícone pré-definido. basic.showIcon(IconNames.Heart) Mostrar emoções básicas, criar animações com ícones.
basic.showNumber(n) Mostra um número na matriz. basic.showNumber(42) Criar um contador, um cronômetro, um termômetro digital.
basic.showLeds("imagem") Mostra uma imagem personalizada 5×5. (vamos ver isso depois) Criar seus próprios desenhos, animações, emoticons personalizados.
basic.pause(ms) Pausa por X milissegundos. basic.pause(500) // meio segundo Controlar o ritmo das suas animações, criar efeitos de suspense.
basic.clearScreen() Apaga toda a matriz de LEDs. basic.clearScreen() Criar um efeito de "reset" visual, iniciar uma animação do zero.
basic.forever(function() {}) Executa o código em loop infinito. basic.forever(function() { ... }) Manter seu programa "vivo", rodando para sempre (até a pilha acabar).
input.onButtonPressed(Button.A, function() {}) Executa quando o botão A é pressionado. input.onButtonPressed(Button.A, function() { ... }) Criar interatividade, fazer o micro:bit responder aos seus comandos.
input.onGesture(Gesture.Shake, function() {}) Executa quando o micro:bit é chacoalhado. input.onGesture(Gesture.Shake, function() { ... }) Criar um dado eletrônico, um alarme anti-furto, um controle por movimento.
input.acceleration(Dimension.X) Lê a aceleração no eixo X. let x = input.acceleration(Dimension.X) Detectar inclinação, criar um nível de bolha, controlar um jogo com o movimento da placa.
Math.randomRange(min, max) Gera um número aleatório entre min e max. let dado = Math.randomRange(1, 6) Criar sorteios, jogos de azar, decisões aleatórias (para quando você não quer decidir nada).

🧠 Como Ler Este Código (Decodificando a Matrix)

// Isso é um comentário. O computador ignora.
// Ele serve para você (e outros) entenderem o que está acontecendo.
// Sinta-se à vontade para escrever comentários ofensivos sobre seu código passado.

basic.showString("OLÁ, MUNDO!") // Mostra "OLÁ, MUNDO!" na tela. Um clássico.

basic.forever(function () { // Loop infinito: roda para sempre, como uma maldição.
  basic.showIcon(IconNames.Heart) // Mostra coração GRANDE. Pura demonstração de afeto digital.
  basic.pause(500) // Espera 500ms. O suficiente para causar expectativa.
  basic.showIcon(IconNames.SmallHeart) // Mostra coração PEQUENO. Apenas para variar.
  basic.pause(500) // Espera 500ms. O ciclo do amor digital.
}) // Volta ao início do loop. A maldição continua.

Tradução: O micro:bit liga, mostra "OLÁ, MUNDO!", e depois fica alternando entre coração grande e coração pequeno para sempre. É um programa. É artístico. É eterno (até a bateria acabar).

🚨 Erros Comuns (E Como Usá-los a Seu Favor)

Erros são seus amigos. Eles te ensinam. Aqui estão alguns clássicos:

Erro O que significa Como resolver
Missing ) in parenthetical Faltou um parêntese. Conte os parênteses. Use um editor que colore o código.
Unexpected token Você escreveu algo que o JavaScript não entende. Verifique se você não escreveu if como iff ou function como funcao.
Cannot find name 'basic' Você esqueceu de importar a biblioteca ou escreveu o nome errado. Verifique a ortografia. O MakeCode já importa, mas se você escrever Basico ao invés de basic, ele não vai entender.

Quando você vir um erro, não entre em pânico. Leia a mensagem. O computador está tentando te dizer algo. Ele é seu parceiro, não seu inimigo.

🚦 PROJETO SIMULADO 01: O Coração Pulsante Psicodélico ❤️

📚 OBJETIVO E CONCEITOS

  • Objetivo: Fazer a matriz de LEDs do micro:bit exibir um coração batendo alternadamente entre grande e pequeno, com um toque psicodélico.
  • Conceitos Ensinados:
    • Loop infinito (basic.forever)
    • Controle de tempo (basic.pause)
    • Exibição de ícones (basic.showIcon)
    • Criação de animações com frames alternados
    • Manipulação de intensidade visual
  • Código BNCC: EF07CI04, EF08CI03
  • Código RCP (Paraná): PR.EF07CI04.s.7.27, PR.EF08CI03.s.8.09

💻 CÓDIGO DO PROJETO

// ================================================================
// PROJETO SIMULADO 01: O Coração Pulsante Psicodélico ❤️
// ================================================================
//
// Este programa faz o coração do micro:bit bater!
// Ele alterna entre um coração GRANDE e um coração PEQUENO
// criando a ilusão de um batimento cardíaco.
//
// Habilidades BNCC: EF07CI04, EF08CI03
// Habilidades RCP-PR: PR.EF07CI04.s.7.27, PR.EF08CI03.s.8.09
// ================================================================

// 🚀 INICIALIZAÇÃO: executado UMA VEZ quando o micro:bit liga
// Mostra uma mensagem de boas-vindas
basic.showString("BATENDO")

// 🔄 LOOP INFINITO: o coração vai bater para sempre!
// basic.forever cria um loop que nunca termina.
// É como um DJ que nunca para de tocar a mesma música.
// ================================================================
basic.forever(function () {
  // ============================================================
  // FRAME 1: Coração GRANDE ❤️
  // ============================================================
  // showIcon exibe um ícone pré-definido na matriz 5x5.
  // IconNames.Heart é o coração grande.
  // ============================================================
  basic.showIcon(IconNames.Heart)

  // ⏰ PAUSA DE 500ms (meio segundo):
  // O coração GRANDE fica visível por 500ms
  // Isso é como a SÍSTOLE (contração do coração)
  basic.pause(500)

  // ============================================================
  // FRAME 2: Coração PEQUENO 💓
  // ============================================================
  // IconNames.SmallHeart é o coração pequeno.
  // Essa alternância cria a sensação de batimento.
  // ============================================================
  basic.showIcon(IconNames.SmallHeart)

  // ⏰ PAUSA DE 500ms (meio segundo):
  // O coração PEQUENO fica visível por 500ms
  // Isso é como a DIÁSTOLE (relaxamento do coração)
  basic.pause(500)
  // ============================================================
  // E ASSIM O LOOP SE REPETE:
  // GRANDE - PAUSA - PEQUENO - PAUSA - GRANDE...
  // Formando um batimento cardíaco contínuo!
  // ============================================================
})

🧪 COMO TESTAR A SIMULAÇÃO

  1. Copie o código para o editor JavaScript do MakeCode.
  2. Observe o simulador - a matriz de LEDs vai começar a piscar o coração.
  3. Veja o ritmo: cada batida dura 500ms.
  4. Interaja: clique com o botão direito no micro:bit virtual para girá-lo.

🏆 DESAFIO "O Batimento Cardíaco Perfeito"

Desafio: Modifique o código para criar um batimento mais realista!

  1. Altere os tempos de pause() para simular diferentes ritmos.
  2. Crie um batimento com pausa longa (600ms) e pausa curta (300ms).
  3. Adicione um terceiro ícone para uma animação mais suave.
  4. Versão insana: Faça o coração acelerar quando você "chacoalhar" o micro:bit no simulador!

Dica: Um coração humano normal bate cerca de 60-100 vezes por minuto. Quantos ms cada batida deve durar? (Dica: 60 batidas/minuto = 1 batida/segundo = 1000ms por batida)

🔘 PROJETO SIMULADO 02: O Detector de Fofoca (Botões Interativos)

📚 OBJETIVO E CONCEITOS

  • Objetivo: Usar os Botões A e B para interagir com o usuário como um detector de fofocas. Botão A = "SIM", Botão B = "NÃO", A+B = "TALVEZ".
  • Conceitos Ensinados:
    • Leitura de entradas digitais (botões)
    • Estruturas condicionais (embutidas nos eventos)
    • Exibição de texto rolante (showString)
    • Interação homem-máquina
  • Código BNCC: EF07CI05, EF08CI04
  • Código RCP (Paraná): PR.EF07CI05.s.7.31, PR.EF08CI04.s.8.13

💻 CÓDIGO DO PROJETO

// ================================================================
// PROJETO SIMULADO 02: O Detector de Fofoca 🔘
// ================================================================
//
// Botão A = "SIM" (você concorda com a fofoca)
// Botão B = "NÃO" (você discorda da fofoca)
// A+B juntos = "TALVEZ" (para os indecisos)
//
// Habilidades BNCC: EF07CI05, EF08CI04
// Habilidades RCP-PR: PR.EF07CI05.s.7.31, PR.EF08CI04.s.8.13
// ================================================================

// 🚀 INICIALIZAÇÃO
// Mostra a pergunta inicial
basic.showString("FOFOCA?")

// ================================================================
// EVENTO DO BOTÃO A -- executado quando o Botão A é pressionado
// ================================================================
// onButtonPressed é um "evento".
// Ele fica ESCUTANDO o botão o tempo todo.
// Quando o botão é pressionado, ele executa o código dentro.
// ================================================================
input.onButtonPressed(Button.A, function () {
  // 🟢 AÇÃO DO BOTÃO A:
  // Exibe "SIM" rolando pela tela
  basic.showString("SIM")
})

// ================================================================
// EVENTO DO BOTÃO B
// ================================================================
input.onButtonPressed(Button.B, function () {
  // 🔴 AÇÃO DO BOTÃO B:
  // Exibe "NÃO" rolando pela tela
  basic.showString("NAO")
})

// ================================================================
// EVENTO DOS BOTÕES A+B JUNTOS (pressionados ao mesmo tempo)
// ================================================================
input.onButtonPressed(Button.AB, function () {
  // 🟡 AÇÃO DOS BOTÕES A+B:
  // Exibe "TALVEZ" -- para os indecisos!
  basic.showString("TALVEZ")
})

🧪 COMO TESTAR A SIMULAÇÃO

  1. Inicie a simulação.
  2. Clique no Botão A no micro:bit virtual.
  3. Clique no Botão B no micro:bit virtual.
  4. Clique em A e B juntos para ver "TALVEZ".

🏆 DESAFIO "A Máquina de Decisões"

Desafio: Transforme o detector em uma máquina de decisões!

  1. Faça o micro:bit exibir "PERGUNTE-ME" no início.
  2. Quando A for pressionado, mostre "SIM" e um ícone feliz.
  3. Quando B for pressionado, mostre "NÃO" e um ícone triste.
  4. Versão insana: Adicione um contador de quantas vezes cada botão foi pressionado e exiba no final.

Dica: Use basic.showIcon(IconNames.Happy) e basic.showIcon(IconNames.Sad).

🎲 PROJETO SIMULADO 03: O Dado Eletrônico (Acelerômetro)

📚 OBJETIVO E CONCEITOS

// ================================================================
// PROJETO SIMULADO 03: O Dado Eletrônico 🎲

🚀 PROJETO SIMULADO 06: O Jogo da Memória (Interação Avançada)

📚 OBJETIVO E CONCEITOS

  • Objetivo: Criar um jogo da memória simples onde o micro:bit mostra uma sequência de LEDs e o jogador deve repeti-la usando os botões.
  • Conceitos Ensinados:

    • Lógica de jogo (estados)
    • Feedback visual e interação

💻 CÓDIGO DO PROJETO

// ================================================================
// PROJETO SIMULADO 06: O Jogo da Memória 🧠
// ================================================================
//
// O micro:bit mostra uma sequência de LEDs que você deve repetir.
// Cada vez que você acerta, a sequência aumenta!
//
// Habilidades BNCC: EF09CI03, EM13CNT101, EM13CNT104
// ================================================================

// ================================================================
// VARIÁVEIS GLOBAIS
// ================================================================
let sequencia: number[] = [] // Armazena a sequência de LEDs
let sequenciaUsuario: number[] = [] // Armazena o que o usuário digitou
let rodadaAtual: number = 0 // Rodada atual do jogo
let jogoAtivo: boolean = false // Estado do jogo

// ================================================================
// FUNÇÃO: gerarSequencia()
// ================================================================
function gerarSequencia() {
  // Gera uma sequência aleatória de números (1-5) para representar as posições
  for (let i = 0; i < 5; i++) {
    sequencia[i] = Math.randomRange(1, 5)
  }
}

// ================================================================
// FUNÇÃO: mostrarSequencia()
// ================================================================
function mostrarSequencia() {
  // Mostra cada número da sequência na tela
  for (let i = 0; i <= rodadaAtual; i++) {
    basic.showNumber(sequencia[i])
    basic.pause(500)
    basic.clearScreen()
    basic.pause(200)
  }
}

// ================================================================
// FUNÇÃO: verificarResposta()
// ================================================================
function verificarResposta() {
  // Verifica se a sequência do usuário está correta até o momento
  for (let i = 0; i <= rodadaAtual; i++) {
    if (sequenciaUsuario[i] !== sequencia[i]) {
      basic.showString("ERROU!")
      basic.pause(1000)
      jogoAtivo = false
      return
    }
  }

  // Se chegou aqui, acertou!
  if (sequenciaUsuario.length == rodadaAtual + 1) {
    basic.showString("ACERTOU!")
    basic.pause(500)
    rodadaAtual++
    sequenciaUsuario = []
    if (rodadaAtual < 5) {
      mostrarSequencia()
    } else {
      basic.showString("VENCEU!")
      jogoAtivo = false
    }
  }
}

// ================================================================
// EVENTO DO BOTÃO A - Adiciona um número à sequência do usuário
// ================================================================
input.onButtonPressed(Button.A, function () {
  if (jogoAtivo) {
    sequenciaUsuario.push(Math.randomRange(1, 5))
    basic.showNumber(sequenciaUsuario[sequenciaUsuario.length - 1])
    basic.pause(300)
    basic.clearScreen()
    verificarResposta()
  }
})

// ================================================================
// EVENTO DO BOTÃO B - Inicia o jogo
// ================================================================
input.onButtonPressed(Button.B, function () {
  if (!jogoAtivo) {
    jogoAtivo = true
    rodadaAtual = 0
    sequencia = []
    sequenciaUsuario = []
    gerarSequencia()
    basic.showString("PRONTO?")
    basic.pause(500)
    mostrarSequencia()
  }
})

// 🚀 INICIALIZAÇÃO
basic.showString("MEMORIA")
jogoAtivo = false

🧪 COMO TESTAR A SIMULAÇÃO

  1. Pressione B para iniciar o jogo.
  2. O micro:bit mostrará uma sequência de números.
  3. Pressione A para adicionar um número à sua resposta.
  4. O jogo verifica se você acertou a sequência.
  5. Se acertar, a sequência aumenta de tamanho!

O navegador vai baixar um arquivo com extensão .hex. É esse arquivo que o micro:bit entende. É o seu código em sua forma mais pura e bruta.

Passo 5: Copie o Arquivo para o micro:bit (A Transferência)

    // 0 = topo/esquerda, 4 = baixo/direita
    // ============================================================
