🔧 Montagem do Hardware (Explicação Detalhada Passo a Passo)

Passo 1: Entendendo os Componentes

O que é um LED?

O LED (Diodo Emissor de Luz) é um componente eletrônico que converte energia elétrica em luz. Ele tem uma característica importante: só permite a passagem de corrente em um sentido (diodo).

  • Ânodo (perna mais longa): conecta ao positivo (pino de saída do micro:bit)
  • Cátodo (perna mais curta): conecta ao negativo (GND do micro:bit)

Por que precisamos de um resistor?

O LED não tem resistência interna significativa. Se ligarmos diretamente ao micro:bit (que fornece 3V), a corrente será muito alta e o LED queimará instantaneamente. O resistor de 220Ω limita essa corrente a um valor seguro (cerca de 10-15mA).

O que é um buzzer?

O buzzer é um componente que converte sinais elétricos em ondas sonoras. No micro:bit, podemos controlar a frequência (altura do som) e a duração usando a função music.playTone().

O que é o micro:bit?

O BBC micro:bit é uma placa microcontroladora com um processador ARM, matriz de LEDs 5x5, botões, acelerômetro, bússola e pinos de entrada/saída (GPIO). É o "cérebro" do nosso projeto.

Passo 2: Conectando os LEDs ao Micro:bit

Vamos conectar os LEDs aos pinos de saída do micro:bit. Cada LED será controlado por um pino específico.

LED Vermelho (Sinal de PARE):

  • Conecte o ânodo (perna longa) do LED vermelho ao pino P0 do micro:bit
  • Conecte o cátodo (perna curta) do LED vermelho a um dos terminais do resistor de 220Ω
  • Conecte a outra ponta do resistor ao pino GND (terra) do micro:bit

LED Amarelo (Sinal de ATENÇÃO):

  • Conecte o ânodo ao pino P1
  • Conecte o cátodo a um resistor de 220Ω e, em seguida, ao GND

LED Verde (Sinal de SIGA):

  • Conecte o ânodo ao pino P2
  • Conecte o cátodo a um resistor de 220Ω e, em seguida, ao GND

Passo 3: Conectando o Buzzer

  • Conecte o terminal positivo do buzzer ao pino P3 do micro:bit
  • Conecte o terminal negativo do buzzer ao pino GND

Passo 4: Verificação do Circuito

Antes de conectar a energia, verifique:

  • Todos os LEDs estão com o ânodo no pino correto e o cátodo no resistor?
  • Os resistores estão conectados corretamente ao GND?
  • O buzzer está conectado ao P3 e GND?
  • Não há fios soltos ou em curto-circuito?

Esquema de Conexão (Vista Superior do Micro:bit)

💻 Código Micro:bit (Completo e Didático)

O código abaixo é extremamente didático, com comentários detalhados em português explicando cada linha. Os alunos devem digitar este código no editor MakeCode, na aba "JavaScript". 

// ==============================================================
// PROJETO: SEMÁFORO SONORO
// DESCRIÇÃO: Simula um semáforo com LEDs e sons, usando o micro:bit
// AUTOR: Equipe Robô na Veia
// VERSÃO: 1.0
// ==============================================================

// ==============================================================
// 1. CONFIGURAÇÕES INICIAIS (DECLARAÇÃO DE VARIÁVEIS)
// ==============================================================

// Definimos os pinos onde cada LED está conectado.
// Usamos números para representar os pinos (0, 1, 2)
let ledVermelho = 0 // LED vermelho no pino P0
let ledAmarelo = 1 // LED amarelo no pino P1
let ledVerde = 2 // LED verde no pino P2

// ==============================================================
// 2. FUNÇÃO PARA ACENDER UM LED ESPECÍFICO
// ==============================================================

/*
Função que acende um LED específico e apaga todos os outros.
Isso garante que apenas um LED fique aceso por vez.
@param {number} pino - O número do pino onde o LED está conectado (0, 1 ou 2)
*/
function acenderLED(pino: number) {
  // PASSO 1: Desliga todos os LEDs primeiro
  // Isso evita que dois LEDs fiquem acesos ao mesmo tempo
  // digitalWritePin(pino, 0) - envia 0V (LOW) para o pino, apagando o LED
  pins.digitalWritePin(DigitalPin.P0, 0)
  pins.digitalWritePin(DigitalPin.P1, 0)
  pins.digitalWritePin(DigitalPin.P2, 0)

  // PASSO 2: Liga o LED no pino especificado
  // digitalWritePin(pino, 1) - envia 3V (HIGH) para o pino, acendendo o LED
  pins.digitalWritePin(pino, 1)
}

// ==============================================================
// 3. FUNÇÃO PARA TOCAR UM SOM
// ==============================================================

/*
Função que toca uma nota musical no buzzer.
@param {number} frequencia - A frequência do som em Hertz (Hz)
@param {number} duracao - A duração do som em milissegundos (ms)
*/
function tocarSom(frequencia: number, duracao: number) {
  // O pino P3 está conectado ao buzzer.
  // music.playTone(frequencia, duracao) toca uma nota na frequência e duração especificadas
  music.playTone(frequencia, duracao)
}

// ==============================================================
// 4. LOOP PRINCIPAL (EXECUTADO CONTINUAMENTE)
// ==============================================================

// O loop 'basic.forever' executa o código repetidamente, para sempre.
// Isso é ideal para um semáforo, que deve funcionar continuamente.
basic.forever(function () {
  // ---------- Sinal VERDE (SIGA) ----------
  // Acende o LED verde e toca um som agudo
  // Chama a função para acender o LED verde
  acenderLED(ledVerde)
  // Toca um som agudo (frequência alta) para indicar "Siga"
  // Nota Dó (523 Hz) por 200ms (milissegundos)
  tocarSom(523, 200)
  // Aguarda 5 segundos com o LED verde aceso
  // 5000 ms = 5 segundos
  basic.pause(5000)

  // ---------- Sinal AMARELO (ATENÇÃO) ----------
  // Acende o LED amarelo e toca um som médio
  acenderLED(ledAmarelo)
  // Toca um som médio para indicar "Atenção"
  // Nota Sol (392 Hz) por 200ms
  tocarSom(392, 200)
  // Aguarda 2 segundos com o LED amarelo aceso
  basic.pause(2000)

  // ---------- Sinal VERMELHO (PARE) ----------
  // Acende o LED vermelho e toca um som grave
  acenderLED(ledVermelho)
  // Toca um som grave (frequência baixa) para indicar "Pare"
  // Nota Dó baixo (262 Hz) por 300ms
  tocarSom(262, 300)
  // Aguarda 5 segundos com o LED vermelho aceso
  basic.pause(5000)

  // O loop recomeça automaticamente - verde, amarelo, vermelho, verde...
})

// ==============================================================
// 5. (OPCIONAL) INÍCIO COM UMA MENSAGEM NA MATRIZ DE LEDs
// ==============================================================

// Quando o micro:bit é ligado, mostra um ícone de coração na matriz de LEDs
// Isso serve como confirmação de que o micro:bit está funcionando
basic.showIcon(IconNames.Heart)
basic.pause(1000) // Mostra o coração por 1 segundo
basic.clearScreen() // Limpa a tela para começar o semáforo

O Modo Noturno é um comportamento onde o semáforo fica com o LED amarelo piscando, indicando atenção em horários de baixo fluxo de veículos. No código, usamos o botão A para ativar/desativar este modo.

// ==============================================================
// PROJETO: SEMÁFORO SONORO COM MODO NOTURNO
// DESCRIÇÃO: Adiciona um modo onde o LED amarelo pisca,
// controlado pelo botão A.
// AUTOR: Equipe Robô na Veia
// VERSÃO: 2.0 (com Modo Noturno)
// ==============================================================

// ==============================================================
// 1. VARIÁVEIS GLOBAIS
// ==============================================================

let ledVermelho = 0 // LED vermelho no pino P0
let ledAmarelo = 1 // LED amarelo no pino P1
let ledVerde = 2 // LED verde no pino P2

// Variável para controlar o modo noturno
// true = modo noturno ativado, false = modo normal
let modoNoturno = false

// ==============================================================
// 2. FUNÇÃO PARA ACENDER UM LED ESPECÍFICO
// ==============================================================

function acenderLED(pino: number) {
  // Desliga todos os LEDs
  pins.digitalWritePin(DigitalPin.P0, 0)
  pins.digitalWritePin(DigitalPin.P1, 0)
  pins.digitalWritePin(DigitalPin.P2, 0)
  // Liga o LED no pino especificado
  pins.digitalWritePin(pino, 1)
}

// ==============================================================
// 3. FUNÇÃO PARA TOCAR UM SOM
// ==============================================================

function tocarSom(frequencia: number, duracao: number) {
  music.playTone(frequencia, duracao)
}

// ==============================================================
// 4. FUNÇÃO PARA APAGAR TODOS OS LEDs
// ==============================================================

function apagarTodosLEDs() {
  pins.digitalWritePin(DigitalPin.P0, 0)
  pins.digitalWritePin(DigitalPin.P1, 0)
  pins.digitalWritePin(DigitalPin.P2, 0)
}

// ==============================================================
// 5. BOTÃO A: ATIVA/DESATIVA O MODO NOTURNO
// ==============================================================

// O botão A do micro:bit é usado como interruptor do Modo Noturno
// Cada vez que é pressionado, o modo é invertido (ligado/desligado)
input.onButtonPressed(Button.A, function () {
  // Inverte o estado da variável modoNoturno
  // !modoNoturno significa "negação do valor atual"
  modoNoturno = !modoNoturno

  // Feedback visual para o usuário
  if (modoNoturno) {
    // Mostra um "V" (check) na matriz de LEDs = modo noturno ATIVADO
    basic.showIcon(IconNames.Yes)
  } else {
    // Mostra um "X" (não) na matriz de LEDs = modo noturno DESATIVADO
    basic.showIcon(IconNames.No)
  }
  basic.pause(500) // Mostra o ícone por 0,5 segundos
  basic.clearScreen() // Limpa a matriz de LEDs
})

// ==============================================================
// 6. LOOP PRINCIPAL
// ==============================================================

basic.forever(function () {
  // VERIFICAÇÃO: Estamos no Modo Noturno?
  if (modoNoturno) {
    // ---------- MODO NOTURNO: LED AMARELO PISCANDO ----------
    // O semáforo fica apenas com o LED amarelo piscando
    // Acende o LED amarelo
    acenderLED(ledAmarelo)
    // Espera 500ms (meio segundo)
    basic.pause(500)
    // Apaga todos os LEDs
    apagarTodosLEDs()
    // Espera 500ms
    basic.pause(500)
    // O loop repete: acende - apaga - acende - apaga
    // Criando o efeito de pisca-pisca
  } else {
    // ---------- MODO NORMAL: SEMÁFORO ----------
    // Funcionamento normal do semáforo (verde - amarelo - vermelho)
    // Sinal VERDE
    acenderLED(ledVerde)
    tocarSom(523, 200) // Nota Dó (agudo)
    basic.pause(5000) // 5 segundos

    // Sinal AMARELO
    acenderLED(ledAmarelo)
    tocarSom(392, 200) // Nota Sol (médio)
    basic.pause(2000) // 2 segundos

    // Sinal VERMELHO
    acenderLED(ledVermelho)
    tocarSom(262, 300) // Nota Dó baixo (grave)
    basic.pause(5000) // 5 segundos
  }
})

// ==============================================================
// 7. INÍCIO COM MENSAGEM
// ==============================================================

// Quando o micro:bit é ligado, mostra uma mensagem de boas-vindas
basic.showString("SEMAFORO")
basic.pause(500)

🔧 Montagem do Hardware (Explicação Detalhada Passo a Passo)

Passo 1: Entendendo o Sensor de Toque Capacitivo

O micro:bit possui um sensor de toque capacitivo integrado nos pinos P0, P1 e P2. Isso significa que podemos usar um simples fio ou até mesmo a nossa pele para enviar um sinal ao micro:bit.

Como funciona?

  • O micro:bit mede a capacitância do pino
  • Quando tocamos o fio, a capacitância muda
  • Essa mudança é medida pelo micro:bit e convertida em um valor numérico (0 a 1023)
  • Quanto maior o contato (mais área de pele), maior a mudança na capacitância

Passo 2: Conexão Simples do Sensor de Toque

Conexão Básica (apenas fio):

  • Conecte um fio jumper ao pino P0 do micro:bit
  • A outra ponta do fio ficará "solta" (sem conexão)
  • O aluno tocará nela para ativar o sensor

Conexão com LED de Calibração (opcional - recomendado):

  • LED: ânodo (perna longa) → pino P2
  • LED: cátodo (perna curta) → resistor 220Ω → GND

Passo 3: Teste de Funcionamento

Teste Manual (sem código):

  1. Conecte o fio ao pino P0
  2. Toque o fio com o dedo
  3. O micro:bit deve detectar o toque (se programado)

Esquema de Conexão:

+------------------------------------------------------------------+
|                             MICRO:BIT                             |
|                                                                  |
|  P0 +-------- FIO SOLTO (SENSOR DE TOQUE)                        |
|  P1 +-------- (NÃO UTILIZADO)                                    |
|  P2 +-------- LED CALIBRAÇÃO (+)                                 |
|  GND +-------- LED CALIBRAÇÃO (-) através do resistor            |
|  GND +-------- FIO SOLTO (completa o circuito)                   |
|                                                                  |
+------------------------------------------------------------------+

Passo 4: Configuração do Sensor no Código

No MakeCode, usamos:

  • pins.analogReadPin(AnalogPin.P0) para ler o valor do sensor (0-1023)
  • Ou o bloco pino P0 é tocado? para detecção digital (toque/não toque)

Para este projeto, usaremos analogReadPin() para obter valores mais precisos.

💻 Código Micro:bit (Completo e Didático)
// ==============================================================
// PROJETO: DETECTOR DE MENTIRAS
// DESCRIÇÃO: O micro:bit "detecta" se você está mentindo usando
// um sensor de toque capacitivo.
// AUTOR: Equipe Robô na Veia
// VERSÃO: 1.0
// ==============================================================

// ==============================================================
// 1. VARIÁVEIS GLOBAIS
// ==============================================================

// A variável 'calibracao' armazena o valor de referência do sensor
// Este valor é lido quando a pessoa está em estado "neutro"
let calibracao = 0

// A variável 'limiar' define o que é considerado "verdade" ou "mentira"
// Quanto menor o limiar, mais sensível o detector
let limiar = 80

// Flag para indicar se o sensor foi calibrado
let calibrado = false

// ==============================================================
// 2. FUNÇÃO DE CALIBRAÇÃO
// ==============================================================

/*
Função que calibra o sensor para a pessoa atual.
Deve ser chamada quando a pessoa está em estado "neutro"
(sem estresse, sem mentir).
*/
function calibrar() {
  // Lê o valor do sensor no pino P0 (0 a 1023)
  // Quanto maior o contato da pele, maior o valor
  calibracao = pins.analogReadPin(AnalogPin.P0)

  // Marca que o sensor foi calibrado
  calibrado = true

  // Acende o LED de calibração (P2) para indicar que está pronto
  pins.digitalWritePin(DigitalPin.P2, 1)

  // Mostra um "V" (check) na matriz de LEDs
  basic.showIcon(IconNames.Yes)
  basic.pause(500)
  basic.clearScreen()

  // Mostra o valor calibrado no display (opcional)
  basic.showString("" + calibracao)
  basic.pause(500)
  basic.clearScreen()
}

// ==============================================================
// 3. FUNÇÃO PARA "DETECTAR MENTIRA"
// ==============================================================

/*
Função principal do detector de mentiras.
Compara o valor atual do sensor com o valor calibrado.
Se a diferença for grande, considera-se "mentira".
*/
function detectarMentira() {
  // Verifica se o sensor foi calibrado
  if (!calibrado) {
    // Se não foi calibrado, pede para calibrar
    basic.showString("CALIBRE")
    basic.pause(500)
    basic.clearScreen()
    return
  }

  // Lê o valor atual do sensor
  let valorAtual = pins.analogReadPin(AnalogPin.P0)

  // Calcula a diferença entre o valor atual e o valor calibrado
  // Usamos Math.abs() para obter o valor absoluto (ignora o sinal)
  let diferenca = Math.abs(valorAtual - calibracao)

  // ==========================================================
  // LÓGICA CONDICIONAL - O CORAÇÃO DO DETECTOR DE MENTIRAS
  // ==========================================================

  // Se a diferença for maior que o limiar, é "mentira"
  if (diferenca > limiar) {
    // ---------- MENTIRA! ----------
    // Feedback: X vermelho + som grave
    // Mostra um "X" na matriz de LEDs (vermelho)
    basic.showIcon(IconNames.No)

    // Toca um som grave (frequência baixa) para indicar mentira
    music.playTone(200, 500)

    // Pisca o LED de calibração (P2) para indicar que algo está errado
    for (let i = 0; i < 3; i++) {
      pins.digitalWritePin(DigitalPin.P2, 0)
      basic.pause(100)
      pins.digitalWritePin(DigitalPin.P2, 1)
      basic.pause(100)
    }

    // Mostra o valor da diferença no display (opcional)
    basic.showString("D:" + diferenca)
    basic.pause(500)
    basic.clearScreen()
  } else {
    // ---------- VERDADE! ----------
    // Feedback: V (check) + som agudo
    // Mostra um "V" (check) na matriz de LEDs (verde)
    basic.showIcon(IconNames.Yes)

    // Toca um som agudo (frequência alta) para indicar verdade
    music.playTone(800, 500)

    // Mostra o valor da diferença no display (opcional)
    basic.showString("D:" + diferenca)
    basic.pause(500)
    basic.clearScreen()
  }

  basic.pause(1000)
  basic.clearScreen()
}

// ==============================================================
// 4. FUNÇÃO PARA RESETAR A CALIBRAÇÃO
// ==============================================================

/*
Função que reseta a calibração, permitindo calibrar para outra pessoa.
*/
function resetarCalibracao() {
  calibrado = false
  pins.digitalWritePin(DigitalPin.P2, 0)
  basic.showString("RESET")
  basic.pause(500)
  basic.clearScreen()
}

// ==============================================================
// 5. FUNÇÃO PARA AJUSTAR O LIMIAR
// ==============================================================

/*
Função que ajusta a sensibilidade do detector.
Quanto menor o limiar, mais sensível (mais "mentiras" são detectadas).
*/
function ajustarLimiar(direcao: number) {
  // direcao: 1 = aumentar (menos sensível), -1 = diminuir (mais sensível)
  limiar = limiar + (direcao * 10)

  // Garante que o limiar não fique negativo ou muito alto
  if (limiar < 10) {
    limiar = 10
  } else if (limiar > 200) {
    limiar = 200
  }

  // Mostra o novo limiar na matriz de LEDs
  basic.showString("L:" + limiar)
  basic.pause(500)
  basic.clearScreen()
}

// ==============================================================
// PROJETO: DETECTOR DE MENTIRAS COM LED DE CALIBRAÇÃO
// DESCRIÇÃO: O micro:bit "detecta" se você está mentindo e
// acende um LED quando calibrado.
// AUTOR: Equipe Robô na Veia
// VERSÃO: 2.0 (com LED de Calibração)
// ==============================================================

// ==============================================================
// 1. VARIÁVEIS GLOBAIS
// ==============================================================

let calibracao = 0 // Valor de referência do sensor
let limiar = 80 // Limiar para considerar "mentira"
let calibrado = false // Flag para indicar se o sensor foi calibrado

// ==============================================================
// 2. FUNÇÃO DE CALIBRAÇÃO
// ==============================================================

function calibrar() {
  // Lê o valor do sensor no pino P0
  calibracao = pins.analogReadPin(AnalogPin.P0)
  calibrado = true

  // Acende o LED de calibração (P2)
  pins.digitalWritePin(DigitalPin.P2, 1)

  // Mostra um ícone para indicar que a calibração foi concluída
  basic.showIcon(IconNames.Yes)
  basic.pause(500)
  basic.clearScreen()
}

// ==============================================================
// 3. FUNÇÃO PARA "DETECTAR MENTIRA"
// ==============================================================

function detectarMentira() {
  // Verifica se o sensor foi calibrado
  if (!calibrado) {
    basic.showString("CALIBRE")
    basic.pause(500)
    basic.clearScreen()
    return
  }

  // Lê o valor atual do sensor
  let valorAtual = pins.analogReadPin(AnalogPin.P0)
  let diferenca = Math.abs(valorAtual - calibracao)

  // Lógica de decisão
  if (diferenca > limiar) {
    // ---------- MENTIRA! ----------
    basic.showIcon(IconNames.No)
    music.playTone(200, 500)

    // Pisca o LED de calibração (indicando que algo está errado)
    for (let i = 0; i < 3; i++) {
      pins.digitalWritePin(DigitalPin.P2, 0)
      basic.pause(100)
      pins.digitalWritePin(DigitalPin.P2, 1)
      basic.pause(100)
    }
  } else {
    // ---------- VERDADE! ----------
    basic.showIcon(IconNames.Yes)
    music.playTone(800, 500)
  }

  basic.pause(1000)
  basic.clearScreen()
}

// ==============================================================
// 4. FUNÇÃO PARA RESETAR A CALIBRAÇÃO
// ==============================================================

function resetarCalibracao() {
  calibrado = false
  pins.digitalWritePin(DigitalPin.P2, 0)
  basic.showString("RESET")
  basic.pause(500)
  basic.clearScreen()
}

// ==============================================================
// 5. CONTROLE POR BOTÕES
// ==============================================================

input.onButtonPressed(Button.A, function () {
  calibrar()
})

input.onButtonPressed(Button.B, function () {
  detectarMentira()
})

input.onButtonPressed(Button.AB, function () {
  resetarCalibracao()
})

// ==============================================================
// 6. INICIALIZAÇÃO
// ==============================================================

basic.showString("DETECTOR")
basic.pause(500)
basic.clearScreen()

// ==============================================================
// PROJETO: JOGO DA MEMÓRIA COM MICRO:BIT
// DESCRIÇÃO: O micro:bit mostra uma sequência de LEDs que o
// jogador deve repetir. Versão com níveis.
// AUTOR: Equipe Robô na Veia
// VERSÃO: 1.0
// ==============================================================

// ==============================================================
// 1. VARIÁVEIS GLOBAIS
// ==============================================================

// Array para armazenar a sequência de LEDs (0 a 24)
// Cada número representa a posição de um LED na matriz 5x5
let sequencia: number[] = []

// Nível atual do jogo (começa em 1)
let nivel = 0

// Índice da jogada atual (qual LED o jogador deve acertar)
let jogadaAtual = 0

// Flag para controle do jogo (true = jogando, false = parado)
let jogando = false

// Tempo entre os LEDs (ms) - controla a velocidade do jogo
let tempoEspera = 500

// Pontuação do jogador
let pontos = 0

// ==============================================================
// 2. FUNÇÃO PARA GERAR UMA SEQUÊNCIA ALEATÓRIA
// ==============================================================

/*
Gera um novo LED aleatório e o adiciona ao final da sequência.
A posição do LED é um número entre 0 e 24.
*/
function gerarSequencia() {
  // Gera um número aleatório entre 0 e 24 (posição de um LED)
  let novoLED = Math.randomRange(0, 24)
  // Adiciona o novo LED ao final da sequência
  sequencia.push(novoLED)
}

// ==============================================================
// 3. FUNÇÃO PARA MOSTRAR A SEQUÊNCIA NA MATRIZ DE LEDS
// ==============================================================

/*
Exibe a sequência de LEDs na matriz, um por vez.
Cada LED acende por um breve período, acompanhado de um som.
*/
function mostrarSequencia() {
  // Limpa a matriz de LEDs
  basic.clearScreen()

  // Para cada LED na sequência
  for (let i = 0; i < sequencia.length; i++) {
    let posicao = sequencia[i]

    // Calcula as coordenadas x e y a partir da posição (0 a 24)
    // x = coluna (0-4), y = linha (0-4)
    let x = posicao % 5 // Resto da divisão por 5 (0, 1, 2, 3, 4)
    let y = Math.floor(posicao / 5) // Divisão inteira por 5 (0, 1, 2, 3, 4)

    // Acende o LED na posição (x, y)
    led.plot(x, y)

    // Toca um som para cada LED (frequência varia com a posição)
    // Frequência: 500 Hz + (posição * 20 Hz)
    music.playTone(500 + posicao * 20, 200)

    // Aguarda para o jogador ver o LED
    basic.pause(tempoEspera)

    // Apaga o LED
    led.unplot(x, y)

    // Aguarda antes do próximo LED
    basic.pause(200)
  }
}

// ==============================================================
// 4. FUNÇÃO PARA INICIAR O JOGO
// ==============================================================

/*
Função que inicia o jogo, resetando todas as variáveis.
*/
function iniciarJogo() {
  // Reseta a sequência e o nível
  sequencia = []
  nivel = 1
  pontos = 0
  jogando = true
  jogadaAtual = 0

  // Mostra o nível atual
  basic.showString("N" + nivel)
  basic.pause(500)
  basic.clearScreen()

  // Gera a primeira sequência
  gerarSequencia()
  mostrarSequencia()

  // Aguarda o jogador
  basic.showString("SUA VEZ")
  basic.pause(500)
  basic.clearScreen()
}

// ==============================================================
// 5. FUNÇÃO PARA VERIFICAR A JOGADA
// ==============================================================

/*
Função que verifica a jogada do jogador.
O jogador usa os botões para confirmar a posição do LED.
(Versão simplificada - em uma versão completa, o jogador
usaria os botões para navegar e confirmar a posição)
*/
function verificarJogada() {
  // Verifica se o jogador acertou todos os LEDs
  // (Nesta versão simplificada, assumimos que o jogador acertou)
  // Em uma versão completa, o jogador usaria os botões para confirmar

  // Avança para o próximo nível
  nivel++
  pontos += 10

  // Mostra o nível atual
  basic.showString("N" + nivel)
  basic.pause(500)
  basic.clearScreen()

// ==============================================================
// PROJETO: ANIMAÇÃO DE DESPEDIDA + SHOW DE LUZES
// DESCRIÇÃO: Exibe uma animação especial de despedida na
// matriz de LEDs, seguida de um show de luzes.
// AUTOR: Equipe Robô na Veia
// VERSÃO: 1.0
// ==============================================================

// ==============================================================
// 1. FUNÇÃO PARA ANIMAÇÃO DE DESPEDIDA
// ==============================================================

/*
Função que exibe uma animação de despedida na matriz de LEDs.
Inclui coração grande, coração pequeno, estrela e "FIM".
*/
function animacaoDespedida() {
  // Animação 1: Coração grande (ocupando toda a matriz)
  basic.showLeds(`
    . # # # .
    # # # # #
    # # # # #
    . # # # .
    . . # . .
  `)
  basic.pause(500)

  // Animação 2: Coração pequeno (no centro)
  basic.showLeds(`
    . . . . .
    . . . . .
    . . . . .
    . . . . .
    . . . . .
  `)
  basic.pause(500)

  // Animação 3: Estrela
  basic.showIcon(IconNames.Stars)
  basic.pause(500)

  // Animação 4: Feliz
  basic.showIcon(IconNames.Happy)
  basic.pause(500)

  // Animação 5: Palavra "FIM"
  basic.showString("FIM")
  basic.pause(500)
}

// ==============================================================
// 2. FUNÇÃO PARA SHOW DE LUZES
// ==============================================================

/*
Função que exibe um show de luzes na matriz de LEDs.
Inclui pisca-pisca e onda de LEDs.
*/
function showDeLuzes() {
  // Fase 1: Pisca-pisca rápido
  for (let i = 0; i < 10; i++) {
    // Acende todos os LEDs
    for (let x = 0; x < 5; x++) {
      for (let y = 0; y < 5; y++) {
        led.plot(x, y)
      }
    }
    basic.pause(100)

    // Apaga todos os LEDs
    for (let x = 0; x < 5; x++) {
      for (let y = 0; y < 5; y++) {
        led.unplot(x, y)
      }
    }
    basic.pause(100)
  }

  // Fase 2: Onda de LEDs
  for (let linha = 0; linha < 5; linha++) {
    for (let coluna = 0; coluna < 5; coluna++) {
      led.plot(coluna, linha)
      basic.pause(50)
    }
    basic.pause(100)
  }

  // Limpa a tela
  basic.clearScreen()
}

// ==============================================================
// 3. LOOP PRINCIPAL
// ==============================================================

// Quando o micro:bit é ligado, executa a animação de despedida
animacaoDespedida()

// Depois, executa o show de luzes
showDeLuzes()

// Por fim, fica em um loop mostrando um coração piscando
basic.forever(function () {
  basic.showIcon(IconNames.Heart)
  basic.pause(1000)
  basic.clearScreen()
  basic.pause(1000)
})
